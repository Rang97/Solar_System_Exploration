# Solar System Exploration

우주와 태양계를 둘러보는 한국어 반응형 웹 페이지입니다. 어두운 우주 배경과 HUD 스타일의 인터페이스로 성운, 은하, 태양계의 행성 및 위성 정보를 소개합니다.

> 이 프로젝트는 개인 프론트엔드 데모입니다. 페이지의 일부 소식과 체험 모집 내용은 예시 콘텐츠입니다.

## 주요 기능

- 메인 비주얼 자동 슬라이드
- 성운·은하 등 우주 가이드 카드
- 태양계 행성과 위성 정보 슬라이더
- 모바일 화면용 사이드 메뉴
- 최신 소식과 우주 가이드를 전환하는 탭
- 데스크톱과 모바일 화면에 대응하는 반응형 레이아웃

## 기술 스택

- HTML
- Tailwind CSS (CDN)
- CSS
- JavaScript
- Swiper 11 (CDN)

별도의 빌드 도구나 패키지 설치 없이 실행할 수 있습니다. Tailwind CSS와 Swiper를 CDN에서 불러오므로 페이지를 볼 때 인터넷 연결이 필요합니다.

## 프로젝트 구조

```text
.
├── index.html      # 페이지 마크업
├── script.js       # 슬라이더, 메뉴, 탭 동작
├── style.css       # HUD 테두리와 슬라이더 등 사용자 스타일
└── img/            # 페이지 이미지 에셋
```
