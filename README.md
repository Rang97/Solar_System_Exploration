# Solar System Exploration

태양계와 우주의 여러 천체를 둘러볼 수 있는 한국어 반응형 웹 페이지입니다. 어두운 배경과 청록색 HUD 스타일을 적용해 성운, 은하, 행성, 위성과 우주 탐사 관련 콘텐츠를 소개합니다.

## 주요 기능

- 성운, 은하, 블랙홀을 소개하는 메인 슬라이드와 우주 가이드
- 태양계 행성 정보 카드
- 달, 이오, 세레스 정보를 보여주는 위성 슬라이더
- 모바일 사이드 메뉴
- 새로운 소식과 미션 가이드 탭 전환
- 화면 크기에 따라 달라지는 반응형 레이아웃

## 사용 기술

- HTML
- Tailwind CSS (CDN)
- CSS
- JavaScript
- Swiper 11 (CDN)

## 프로젝트 구조

```text
.
├── index.html  # 페이지 구조와 콘텐츠
├── script.js   # 슬라이더, 모바일 메뉴, 탭 동작
├── style.css   # HUD 장식과 슬라이더 사용자 스타일
└── img/        # 페이지에서 사용하는 이미지
```

## 참고

페이지의 소식과 일부 우주 탐사 콘텐츠는 화면 구성을 위한 예시입니다. 실제 뉴스나 최신 임무 정보로 활용하기 전에는 별도로 사실 여부를 확인해 주세요.
